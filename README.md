# Property Sales (Propwise)

Production-grade Next.js + Prisma + MySQL project with standardized build and deployment flow.

## Tech Stack
- Next.js 15 (App + Pages Router)
- React 19
- Prisma ORM
- MySQL
- NextAuth

## Prerequisites
- Node.js 20+
- npm 10+
- MySQL (XAMPP is supported)

## Local Setup
1. Install dependencies:
```bash
npm ci
```

2. Create environment file:
```bash
cp .env.example .env
```

3. Prepare database:
- Option A (recommended): use Prisma
```bash
npm run gen
npm run db:push
```
- Option B (XAMPP/phpMyAdmin): use SQL file
`scripts/sql/init_xampp.sql`

4. Run development server:
```bash
npm run dev
```

## Quality Commands
```bash
npm run lint
npm run typecheck
npm run build
```

## Production Build
This project is configured for standalone output:
- `next.config.ts` -> `output: "standalone"`

Linux build artifact is generated by:
- `.github/workflows/build-linux.yml`

## Deployment (Shared Hosting / cPanel)
Use Linux-built artifacts only (never upload Windows `.next`).

See:
- `DEPLOYMENT.md`

## Security Notes
- Do not commit `.env`
- Rotate secrets if exposed
- Keep dependencies updated through PRs + workflow rebuilds
